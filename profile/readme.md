# Pré-Hackathon FATEC Itaquera

Curso preparatório de alunos para alunos, criado para dar a todo mundo, independente do nível de experiência, uma chance justa de chegar bem no **1° Hackathon da FATEC Itaquera**.

**Duração:** 18/09/2026 a 25/09/2026 (7 dias) · **[Assista à live de abertura](https://youtu.be/DqYW7r8F618?si=wsBNnBHqml8hHicc)**

---

## 🛤️ Trilhas com repositório nesta organização

| Trilha | Repositório | Conteúdo em vídeo |
|---|---|---|
| PHP Iniciante | [trilha-iniciante-php](https://github.com/Pre-Hackton-Fatec-Itaquera/trilha-iniciante-php) | [Playlist](https://www.youtube.com/playlist?list=PLC2N4JRAGB5E) |
| Python Intermediário | [trilha-pythaon](https://github.com/Pre-Hackton-Fatec-Itaquera/trilha-pythaon) | — |
| JavaScript Full-Stack Intermediário — Frontend | [Javascript-frontend-intermediario](https://github.com/Pre-Hackton-Fatec-Itaquera/Javascript-frontend-intermediario) | [Playlist](https://www.youtube.com/playlist?list=PLYE29tfcrWEk) |
| JavaScript Full-Stack Intermediário — Backend | [Javascript-backend-intermediario](https://github.com/Pre-Hackton-Fatec-Itaquera/Javascript-backend-intermediario) | [Playlist](https://www.youtube.com/playlist?list=PLYE29tfcrWEk) |

Um resumo rápido de cada uma:

**PHP Iniciante** — versão simplificada do app *Professor Mensuring* (avaliação de professores) em PHP puro + MySQL + HTML/CSS, pensada para quem está começando agora. Entregue de propósito incompleto, com desafios para o aluno completar.

**Python Intermediário** — trilha em módulos (história da linguagem, lógica de programação, estruturas de dados, paradigmas e boas práticas, fundamentos da web, desenvolvimento web com Python), com gabaritos de exercícios e templates de apoio.

**JavaScript Full-Stack Intermediário** — o mesmo projeto *Professor Mensuring* construído em duas pontas: um backend em Node/TypeScript (Drizzle ORM, camadas de rotas/services/repository, testes) e um frontend em React + Vite + Tailwind (roteamento, camada HTTP, formulários com validação, componentização). O Node ainda é necessário para rodar o frontend, mas o backend já sobe pronto via Docker (como imagem, sem precisar rodar o código dele), então quem for fazer só o frontend não precisa instalar banco de dados nem montar o backend na própria máquina.
